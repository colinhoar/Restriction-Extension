Extension Testing & Verification Page

👋 Welcome!

Use this page to verify that your Focus Guardian extension is installed and working correctly. Follow the tests below to ensure everything is functioning as expected.

Test 1: Instagram Blocking

Click the button below to test Instagram blocking. If the extension is working, you should see a purple blocking screen instead of Instagram.

🚫 Test Instagram Block

Expected Behavior:

  • Purple gradient blocking screen appears
  • Message: "Instagram is Blocked"
  • Countdown timer (5-10 seconds)
  • Automatic redirect after countdown
  • Cannot access Instagram without disabling extension

Test 2: YouTube Focus Mode

Click the button below to test YouTube focus mode. You should be redirected to your Watch Later playlist with no recommendations visible.

🎯 Test YouTube Focus

Expected Behavior:

  • Homepage redirects to Watch Later playlist
  • No recommended videos in sidebar
  • No homepage feed visible
  • Comments section hidden (optional)
  • No end-screen recommendations after videos

Test 3: Extension Popup

Click the Focus Guardian icon in your Chrome toolbar to test the popup interface.

Expected Elements:

  • Status indicator (green = active, red = disabled)
  • "Disable Protection" or "Enable Protection" button
  • Disable attempts counter
  • Motivational quote
  • Extension description

Test 4: Challenge System

Test the psychological friction system by trying to disable the extension.

Steps:

  • Click the extension icon
  • Click "Disable Protection" button
  • You'll receive one of three random challenges
  • Complete the challenge to disable
  • 30% chance of being denied (probabilistic frustration)

Challenge Types:

  • Math: Solve multiplication problem (e.g., 72 × 39)
  • Typing: Type random 15-20 character string exactly
  • Timer: Wait 5-15 seconds before confirming

Test 5: Re-enabling Protection

After disabling the extension, test re-enabling it. This should be simple and friction-free.

Expected Behavior:

  • Click "Enable Protection" button
  • No challenge required
  • Instant activation
  • Status indicator turns green
  • Pages reload to apply protection

✅ Installation Verification Checklist

  • Extension appears in chrome://extensions/
  • Icon visible in Chrome toolbar
  • Instagram completely blocked when active
  • YouTube homepage redirects to Watch Later
  • YouTube recommendations hidden
  • Popup opens with correct status
  • Challenge appears when disabling
  • Re-enabling works without friction

🔧 Troubleshooting

Extension not working?

  • Enable Developer Mode in chrome://extensions/
  • Click reload icon on the extension card
  • Check for console errors (F12)
  • Make sure extension has required permissions

YouTube recommendations still showing?

  • Refresh the YouTube page
  • Open YouTube in a new tab
  • Wait a few seconds for content scripts to execute

Challenge not working?

  • Check that you typed/calculated correctly
  • Try closing and reopening the popup
  • Clear extension storage and reload
